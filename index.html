🎨 Effects & color

LIVE CSS FILTERS

These color adjustments affect the preview and the canvas-based video export. They are basic filters, not a full professional color-grading pipeline.

Transitions, keyframes, masking, chroma key, LUT import, motion tracking, and compositing need a more advanced rendering engine and are planned as later modules.

💬 Captions & text

The current exporter burns a single title overlay into the output. Timed subtitle tracks, word-by-word karaoke captions, font uploads, and multiple text layers need timeline-engine work.

🛡️ Security roadmap

Production accounts require server-side authentication, secure storage rules, rate limits, privacy policy, and secret management.

Do not put passwords, private API keys, payment credentials, or cloud service secrets in index.html or a public GitHub repository. A public website alone cannot safely protect secret keys.
